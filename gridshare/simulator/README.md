# GridShare Smart-Meter Telemetry Simulator

The simulator provides high-fidelity, synthetic energy telemetry streams and deterministic demo scenarios for the GridShare platform.

> [!NOTE]
> **Data Transparency Notice**: All data records generated by this simulator are strictly synthetic/illustrative and stamped with `source: "SIMULATED"`.

---

## Capabilities
1. **Realistic Diurnal Patterns**:
   - Morning demand surge (7:00 AM – 10:00 AM)
   - Midday solar generation peak curve (11:00 AM – 3:00 PM)
   - Evening peak cooking/lighting/EV demand surge (6:00 PM – 10:00 PM)
   - Household profile variation (Solar Prosumers vs EV Consumers)
2. **Deterministic PPT Demo Reproduction**:
   - **House A**: `6.8 kW` Gen / `2.1 kW` Con (`+4.7 kW` Surplus)
   - **House B**: `1.2 kW` Gen / `4.0 kW` Con (`-2.8 kW` Deficit)
   - **Community Battery**: `40% SOC` (50 kWh)
   - **Grid Price**: `₹6.10/kWh`
3. **Dual Protocol Transmission**:
   - REST API: `POST /api/telemetry`
   - Optional MQTT: `gridshare/telemetry`

---

## How to Run

```bash
# 1. Run live continuous stream (every 3 seconds)
python -m gridshare.simulator.run_simulator --mode live --interval 3.0

# 2. Run deterministic PPT demo scenario
python -m gridshare.simulator.run_simulator --mode ppt

# 3. Ingest 24-hour historical batch
python -m gridshare.simulator.run_simulator --mode history --hours 24
```
